# sharpdroid compatibility

this is a game compatibility tracker for sharpdroid, an android app that runs SharpEmu.

## rules

please read these and comply when posting issues! <a target="_blank" rel="noopener noreferrer" href="https://support.mircowuffwuff.com"><img width="24" align="top" src=".github/images/mircomoji-X3-flat.png"/></a>

| no | rule |
|-|-|
| i | **one** issue **per game**. please search for an existing issue for your game and *reply to that*, instead of posting a new issue! |
| ii | please **describe** the game experience! e.g. "the game crashed during bootup", "the game got to the title screen but crashes on New Game", "the game gets to gameplay but the main character is invisible", ... |
| iii | please include **game** id and version, **device**, **SoC**, **sharpdroid** version, **SharpEmu build** version, and **graphics driver** information! a log would be the cherry on top, but you dont have to. |
